# 1Life App Store 截图计划（草案）

最后更新：2026-07-14

建议先制作 6 张 iPhone 6.7 英寸截图，并按同一套 Family UI V2 视觉规范排版。

## 截图顺序

1. **Dashboard 总览**：日期、热量进度、宏量营养、饮水和快捷记录。
2. **饮食时间线**：早餐/午餐/晚餐分组，同一餐次多条食物和营养汇总。
3. **AI 餐食识别**：图片或文字输入、确认食物、校对每份营养后入库。
4. **训练闭环**：训练记录、周目标、连续训练和 Apple Health 导入入口。
5. **身体与阶段回顾**：身体数据、营养趋势、训练摘要和周期洞察。
6. **资料库与导出**：餐食库、饮品/补剂品牌分组、PDF/CSV/JSON 导出。

## 拍摄要求

- 使用有代表性的本地演示数据，不出现真实姓名、API Key、健康敏感信息或真实照片；
- 每张图只突出一个核心卖点，避免过多弹窗和长文本；
- 保持中文文案、浅色和深色版本的视觉一致；
- 在截图前确认底部 Tab、键盘、弹窗和安全区处于稳定状态；
- 最终截图必须来自实际运行版本，不能用静态 mock 代替功能界面。

## 文案方向

- “把每天的饮食、训练和身体状态放在一起”；
- “先识别，再由你确认”；
- “每份营养、每餐记录、长期趋势”；
- “本地优先，数据可导出”。
