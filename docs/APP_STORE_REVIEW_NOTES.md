# 1Life App Store 审核说明（草案）

最后更新：2026-07-14

## 产品用途

1Life 是个人饮食、训练、身体数据、习惯和日志记录工具。它帮助用户整理个人记录，不提供诊断、治疗或处方建议。

## 审核路径

1. 首次启动完成 Onboarding，AI 配置可以跳过。
2. Dashboard 可查看日期、饮食摘要和快捷记录。
3. 饮食页可手动添加餐食，也可以从餐食库、模板库和最近记录快速复用。
4. 设置 → 餐食营养识别、饮品营养识别、补剂营养识别可使用文字或图片输入；识别结果必须经用户校对后保存。
5. 设置 → Apple Health 可在用户授权后导入支持的数据。
6. 设置 → 数据与同步可导出 CSV、PDF 和 JSON，也可覆盖导入 JSON 备份或清空本机数据。

## AI 配置

AI 功能需要用户自行配置服务商和 API Key。审核测试可以跳过 AI 配置，使用手动记录、模板和本地库功能。AI 请求会使用设置中当前选择的服务商、模型和 Key。

## 权限用途

- 相机/照片：识别食品、饮品、补剂标签和选择个人照片。
- Apple Health：用户授权后辅助读取活动、身体数据和训练记录。
- 通知：用户开启提醒后发送本地提醒。

## 健康与营养声明

应用中的热量、营养、TDEE、训练和趋势信息仅供个人记录与参考，不是医疗建议，不用于诊断、治疗、预防疾病或替代专业人士。应用不保证 AI 识别结果、数据库数据或第三方健康数据绝对准确。

## 提交前必须补充

- 正式隐私政策 URL 和联系邮箱；
- 测试账号或明确的无账号审核路径；
- 当前版本实际支持的 HealthKit 类型清单；
- App Store Connect 中的年龄分级、数据收集声明和截图；
- 真机权限、导出、恢复、清空和 AI 失败路径的运行记录。
